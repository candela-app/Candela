Mono repo for Candela applications:

- `apps/candela-app` — website frontend (module walkthroughs live next to each game under `src/components/*/WALKTHROUGH.md`)
- `apps/candela-backend` — shared backend (website, mobile, TV). Roles, auth, and APIs: [`apps/candela-backend/WALKTHROUGH.md`](apps/candela-backend/WALKTHROUGH.md)
- `apps/candela-mobile` — mobile frontend
- `apps/candela-tv` — TV frontend
- `packages/shared` — shared code across apps
